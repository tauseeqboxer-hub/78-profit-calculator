# 78 Profit Calculator — Android APK Build Guide (GitHub Actions)

1. GitHub par naya repository banayein: `78-profit-calculator`
2. Is ZIP ko unzip karein aur `pubspec.yaml`, `lib/`, aur `assets/` upload kar ke **Commit changes** karein.
3. GitHub par **Actions -> set up a workflow yourself** par click karein, `.github/workflows/main.yml` ka code paste karein aur **Commit changes** daba dein.
4. 3–4 minute mein **Actions** tab mein green tick (✓) aa jayega — niche **Artifacts** se `78-Profit-Calculator-APK` download kar ke apne Android phone mein install kar lein!
